# 图片压缩工具使用说明 | Image Compressor User Guide

## 功能简介 | Introduction

**中文**：  
这是一个纯前端的图片压缩工具，可以帮助您快速压缩图片，减小文件大小，适合网络传输和分享。

**English**：  
This is a pure front-end image compression tool that helps you quickly compress images, reduce file size, and make them suitable for network transmission and sharing.

## 主要特点 | Key Features

**中文**：
- **支持JPG和PNG格式**：可以处理最常见的两种图片格式
- **文件大小显示**：清晰展示压缩前后的文件大小对比
- **压缩质量可控**：通过滑块调节压缩质量，平衡文件大小和图片质量
- **本地处理**：所有压缩过程在本地浏览器中完成，不会上传至任何服务器，保护您的隐私
- **中英文支持**：支持中文和英文两种语言界面

**English**：
- **JPG and PNG Support**: Handles the two most common image formats
- **File Size Display**: Clearly shows the file size comparison before and after compression
- **Adjustable Quality**: Control compression quality via a slider to balance file size and image quality
- **Local Processing**: All compression is done in your local browser, no uploads to any server, protecting your privacy
- **Multilingual Support**: Supports both Chinese and English interfaces

## 使用方法 | How to Use

### 中文

1. **上传图片**：
   - 点击"选择图片"按钮选择本地图片文件
   - 或者直接将图片文件拖放到上传区域

2. **压缩设置**：
   - 上传图片后，使用滑块调整压缩质量（数值越高，压缩后质量越好，但文件减小的幅度也越小）
   - 点击"压缩图片"按钮开始压缩

3. **预览和下载**：
   - 压缩完成后，您可以在页面上预览原始图片和压缩后的图片效果
   - 查看压缩前后的文件大小和压缩率
   - 点击"下载压缩图片"按钮保存压缩后的图片到本地
   - 如需处理新图片，点击"重新上传"按钮

4. **切换语言**：
   - 点击右上角的"切换语言"按钮
   - 选择您偏好的语言（中文或英文）

### English

1. **Upload Image**:
   - Click the "Choose Image" button to select a local image file
   - Or drag and drop an image file to the upload area

2. **Compression Settings**:
   - After uploading, use the slider to adjust compression quality (higher values mean better quality but less size reduction)
   - Click "Compress Image" button to start compression

3. **Preview and Download**:
   - After compression, you can preview both original and compressed images on the page
   - Check file size before and after, along with the compression rate
   - Click "Download Compressed Image" to save the compressed image to your device
   - To process a new image, click "Upload New Image"

4. **Switch Language**:
   - Click the "Switch Language" button in the top-right corner
   - Select your preferred language (Chinese or English)

## 注意事项 | Notes

**中文**：
- 浏览器可能对文件大小有限制，一般不建议上传超过5MB的图片
- 压缩过程可能需要几秒钟，取决于图片大小和您的设备性能
- 对于已经高度压缩的图片，再次压缩可能效果不明显
- 对于PNG格式的透明图片，压缩后会保留透明度

**English**：
- Browsers may have file size limitations; generally not recommended to upload images larger than 5MB
- Compression may take a few seconds, depending on image size and your device performance
- For already highly compressed images, further compression may not show significant results
- For PNG images with transparency, transparency will be preserved after compression

## 技术说明 | Technical Notes

**中文**：  
本工具使用HTML5的Canvas API进行图片压缩，所有处理都在您的浏览器中完成，无需联网，也不会将您的图片上传到任何服务器。

**English**：  
This tool uses HTML5 Canvas API for image compression. All processing is done in your browser, requires no internet connection, and does not upload your images to any server.
