# 图片压缩网站

这是一个简单易用的在线图片压缩工具，可以帮助用户快速压缩图片文件大小而尽量保持图片质量。

## 功能特点

- 支持上传 PNG、JPG 等常见图片格式
- 提供原图和压缩后图片的预览
- 显示压缩前后的文件大小对比
- 允许用户自定义压缩质量/比例
- 支持压缩后图片的下载
- 简洁美观的苹果风格界面设计

## 页面结构

### 主页 (index.html)

主页采用简洁的单页面设计，包含以下主要区域：

1. **头部区域**：包含网站标题和简短介绍
2. **上传区域**：拖放上传框和上传按钮
3. **压缩设置区域**：压缩质量滑块控制
4. **预览区域**：左侧原图预览，右侧压缩后图片预览
5. **信息区域**：显示文件名、格式、压缩前后大小等信息
6. **操作区域**：下载按钮和重新上传按钮
7. **底部区域**：简单的版权信息

## 技术实现

- 使用纯 HTML5、CSS3 和 JavaScript 实现，无需后端服务器
- 采用 HTML5 File API 处理文件上传
- 使用 Canvas API 进行图片压缩处理
- 使用 CSS Flexbox 和 Grid 实现响应式布局
- 应用苹果风格的设计元素：圆角、浅色阴影、磨砂玻璃效果等

## 使用方法

1. 打开网站首页
2. 点击上传按钮或将图片拖放到指定区域
3. 调整压缩质量/比例滑块
4. 预览压缩效果和文件大小变化
5. 满意后点击下载按钮保存压缩后的图片
